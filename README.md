# Mod of Mod v0.2.0 (Fabric 26.3) — 시험 개발본

**실제 GitHub Actions 빌드 및 게임 내 정상 동작은 검증되지 않았습니다.** 반드시 백업 서버에서 시험하세요.

## 이번 변경
- 바닐라 지도 자동 지급을 중단하고 우측 상단 256블록 범위의 **플레이어 레이더**로 전환했습니다. J키로 토글합니다. 레이더는 같은 차원의 근처 플레이어만 표시하며, 지형이나 몹을 추적하지 않습니다.
- 발전과제 알림을 짙은 남색·금색 카드형으로 바꾸고 슬라이드·코인 맥동 애니메이션과 높은 대비의 큰 글씨로 변경했습니다. `[5코인]+` 보상 표시는 그대로 유지합니다.
- 상점의 등장 애니메이션과 관리자 전용 청록색 패널을 추가했습니다.
- OP 전용 `/관리자`: OP는 전용 패널을 열며, 서버 콘솔에서는 접속 현황과 버전을 출력합니다.
- OP 또는 콘솔에서 `/업데이트 https://github.com/pullgena/mod-of-mod`를 실행하면 최신 **공식 공개 GitHub Release**를 조회합니다.
- 게임 메인 화면의 **Mod of Mod 업데이트** 버튼으로 클라이언트 모드도 릴리스를 확인하고 업데이트할 수 있습니다. 이 동작은 서버에서 클라이언트를 강제로 업데이트시키는 것이 아닙니다.

## 업데이트 보안
- 임의 저장소 URL은 보안상 거부합니다. `https://github.com/pullgena/mod-of-mod`만 허용합니다.
- Release의 `mod-of-mod-VERSION.jar` 파일과 SHA-256 digest를 검사하고 JAR 안의 `fabric.mod.json` 모드 ID와 버전을 확인합니다.
- 설치한 JAR이 하나라고 확인되는 환경에서는 백업 후 교체하여 **다음 시작 시 적용**합니다.
- Windows 등의 실행 중 JAR 잠금이나 파일 권한 오류 시 검증 파일을 `mods/.modofmod-updates/`에 보관하고 수동 적용 방법을 안내합니다.
- **자동 재시작은 하지 않습니다.** 서버와 각 클라이언트에서 별도로 확인하고 종료·재시작해야 합니다.
- 사용자가 작성한 설정·코인 기록·월드에는 손대지 않도록 구성했지만 업데이트 전 별도의 서버 백업을 권장합니다.
- 릴리스가 아직 게시되지 않았다면 업데이트할 대상이 없다는 메시지만 표시합니다.

## 설치
Minecraft Java Edition 26.3 / Fabric Loader 0.19.5+ / Fabric API 0.163.0+26.3 / Java 25.

서버 및 **각 플레이어 PC에 동일한 Mod of Mod JAR**을 설치합니다. Simple Voice Chat도 서버와 PC에 별도로 설치하세요.

- `B` 상점 열기
- `J` 레이더 토글
- `V` Simple Voice Chat 메뉴
- `M` Simple Voice Chat 마이크 음소거
- `/관리자` OP 관리자 패널
- `/업데이트 https://github.com/pullgena/mod-of-mod` OP·콘솔 업데이트 확인

발전과제마다 코인을 지급하고 서버에서 UUID별로 지급 이력을 저장합니다. 이전 버전의 `config/modofmod-players.json` 데이터 구조는 유지합니다. 기존 지도 아이템을 강제 삭제하지 않으며 새 플레이어에게 지급하지 않습니다.

## 주의
2인 서버 기준 1초 간격 레이더 업데이트, 256블록 밖의 플레이어 숨김. 코인·구매는 서버만 처리합니다.

원하는 기능 중 **실시간 지형 레이더, 다양한 화면별 전용 텍스처, 관리자 코인 지급/차감, 완전히 검증된 무중단 자동 업데이트**는 아직 포함되지 않았습니다.
